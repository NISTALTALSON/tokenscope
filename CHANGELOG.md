# Changelog

All notable changes to TokenScope are documented here. The project is currently in an early MVP phase, so entries favor user-visible behavior and repository-level changes over internal implementation detail.

## [Unreleased]

- Improved repository presentation and contributor documentation.
- Added a GitHub Actions workflow for typechecking, tests, and production builds.
- Added an explicit MIT license.

## [0.1.0] — Initial Phase 1 MVP

- Local-first dashboard for token usage, requests, providers, models, and cost confidence.
- CSV, JSON, and JSONL imports with aliases, mapping, validation, duplicate detection, and review details.
- Manual usage records and CSV/JSON/JSONL exports.
- IndexedDB persistence with localStorage fallback and labelled DEMO records.
- Versioned API-equivalent pricing, actual-vs-estimated cost presentation, subscription settings, and budget headroom.
- Timezone-aware analytics, historical forecasts, and saved startup scenarios.
- Domain and application smoke tests.
